\section{JWTs}

\begin{frame}{JWT}
  JWT (JSON Web Token) é um formato padronizado para transportar
  informações entre sistemas de forma compacta e verificável.
  \begin{center}
    \includegraphics[width=0.6\textwidth]{jwt}
  \end{center}
\end{frame}

\begin{frame}{Bearer Token}
  \begin{itemize}
    \item Bearer Authentication é um mecanismo de autenticação HTTP em
      que o cliente envia um token junto com a requisição.
    \item O nome ``Bearer'' significa literalmente: ``Quem portar esse
      token pode usá-lo.''
    \item A API não verifica quem está segurando o token; ela apenas
      verifica se o token é válido.
  \end{itemize}
\end{frame}
